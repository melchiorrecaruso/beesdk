The Bee 0.7.9 build 0602 archiver utility, freeware version, Oct 2026.
(C) 1999-2026 Andrew Filinsky and Melchiorre Caruso.

  Usage: Bee <Command> -<Option 1> -<Option N> <ArchiveName> <FileNames...>

  Commands:

    a   Add files to archive
    d   Delete files from archive
    e   Extract files from archive
    x   eXtract files from archive with path name
    l   List archive
    t   Test archive files
    r   Rename files in archive

  Options:

    r       Recurse subdirectories
    u       Update files
    f       Freshen files
    e       force file Extention
    s       create Solid archive
    a       add self-extrActor module
    o<mode> set overwrite file Mode (Q-Query (default), A-All, S-Skip all)
    m<0..3> set compression Method (0-store...1-default...3-maximal)
    d<0..9> set Dictionary size (d1 uses < 5M, d2 (default) < 10M, d3 < 20M...)

    x       eXclude filenames
    t       Test archive after process
    l       List archive after process
    y       set temporany directory
    k       use blowfish crypter/decrypter (min key-length 4 bytes)
    cd<dir> set current archive directory

    cfg<filename> use specified configuration file
    pri<priority> set process Priority (0-Idle, 1-Normal, 2-High, 3-RealTime)

    -exe-filter   preprocess executables (x86, x64, ARM64; found by content)
    -mixer        context mixing on the PPM model (smaller, slower, more memory)

  Use BeeOpt to make most optimal parameters.

  Notes on the long options (two dashes on the command line, e.g. --mixer):

    --exe-filter  Executables (PE and ELF for x86, x86-64 and ARM64) are
                  recognized from their content, not from the extension,
                  and transformed before compression; other files are
                  stored as usual. Typical gain on executables: 5-18%.

    --mixer       Codes data with a context mixer on top of the PPM model.
                  On the reference corpora (Calgary, Canterbury, Silesia)
                  archives are 7-12% smaller than with PPM alone at d5, but
                  compression and extraction are several times slower
                  (about 3x at d5, up to 9x with small dictionaries). The
                  mixer needs 2^(14+d) * 1152 bytes of memory in addition
                  to the dictionary: 18 MiB at d0, 72 MiB at d2, 576 MiB
                  from d5 upwards.

    Both options apply to the a and d commands (d recodes the files that
    follow a deleted one in a solid archive), are off by default and can
    be combined. Extraction needs no option: the archive records how each
    file was coded. Archives created with them can be extracted only by
    Bee 0.7.9 build 0602 or later; without them, archives are the same as
    before.
